# 🎸 ネオ・ブルース・コンポーザー (Neo Blues Composer)

**泥臭さ × 現代重低音** ── これからバズる新世代ブルース曲ジェネレーター

ミシシッピ・デルタの魂、歪んだチューブアンプ、12小節ブルースの伝統と、現代SNS（TikTok / YouTube Shorts / Reels）で耳を一瞬で奪う「キラーリフ」「808重低音」「しゃがれ声のAABコール＆レスポンス」をハイブリッドに融合したAI音楽プロンプト作成Webツールです。

---

## 🌐 公開ページ（GitHub Pages）

- **公開URL**: [https://ohapee.github.io/neo-blues-composer/](https://ohapee.github.io/neo-blues-composer/)
- スマートフォン（iPhone / Android）およびパソコンのモダンブラウザでそのまま動作します。
- インストール不要・完全無料・PWA（Progressive Web App）対応。ホーム画面に追加してアプリとして利用できます。

## ✨ 主な特徴とこだわり

### 1. 伝統のブルース × 現代バズ要素のハイブリッド
- **ネオ・ガレージ・ファズ**: The Black Keys や Jack White のような、爆音ファズギターと極太ドラム。
- **サイバー・トラップ・ブルース**: 地を這う808サブベースと泥臭いボトルネックスライドが絡み合う新世代バイラルスタイル。
- **デルタ・スワンプ**: 木造ポーチを踏み鳴らす足拍子（Stomp）とリゾネーターギターの生々しい叫び。
- **シカゴ・エレクトリック**: 真空管アンプを限界まで歪ませたブルースハープ（ハーモニカ）とスティングギター。
- **テキサス・シャッフル**: Stevie Ray Vaughan 直系の爽快で切れ味鋭い高速シャッフル。
- **ミッドナイト・ソウル・バー**: 煙草の煙とウイスキー、泣きのサックス＆ハモンドオルガンが沁みるスローブルース。

### 2. 現代人の悲哀・愚痴から「AAB形式ブルース歌詞」を自動生成
ブルース伝統の「同じフレーズを2回繰り返し（AA）、3行目でオチや結末を叫ぶ（B）」構造を現代向けに再構築：
- **残業・締め切り・終わらない仕事**: 「昨日の夜もオフィスで夜が明けた…」
- **金欠・物価高・空っぽの財布**: 「給料日だってのに財布には木枯らしが吹いている…」
- **スマホ・SNS疲れ・通知地獄**: 「ピコンと鳴るたび胸の奥が痛みだす…」
- **真夜中の孤独・やるせなさ**: 「午前3時、すべての街灯が消えて一人きり…」
- **大人の失恋・すれ違い**: 「お前が出て行った部屋は、まるで嵐のあと…」

### 3. Web Audio API によるリアルタイム・ブルース試聴
- ブラウザ上の内蔵シンセサイザーで、**「12小節ブルース進行」×「シャッフルスイングビート」×「チューブアンプ歪みサチュレーション」×「ウォーキングベース」** をリアルタイム合成演奏。
- 12小節の進行に合わせて、画面上の真空管インジケーターがリアルタイムにオレンジ色に点灯します。

### 4. ボカロボーカル対応（新機能・ギャップ萌えハイブリッド）
- **Hyper-Kawaii ボカロボーカル**: とびきりキュートで超高音な電波系ボカロ。早口や甘いアニメ声で泥臭いブルースを歌い上げ、強烈なインパクトを生み出します。
- **Yami-Kawaii ボカロボーカル**: 儚げで壊れそうなウィスパーボイスと、感情が崩壊した歪んだ叫びが交錯する病みかわボカロ。心のリアルな痛みをブルースのグルーヴに乗せて叫びます。
- **ボカロ専用プリセット**: 「🎀 電波系Hyper-Kawaiiブルース」「🖤 病みかわYami-Kawaiiブルース」を標準搭載。ワンクリックで異色の化学反応を楽しめます。
- **試聴プレビュー連動**: 試聴プレビュアーでも、ボカロ選択時に高音ピコピコシンセや不安定なピッチベンドがブルースに乗ってリアルタイム演奏されます。

### 5. 主要AI音楽モデルに最適化
- **Suno / Udio**: スタイル指定タグと構造化された歌詞ブロック（`[Intro - Killer Riff]`, `[Verse 1 - AAB]`, `[Guitar Solo]`）を自動出力。
- **Google Flow Music**: 音響特性や楽器編成を緻密に指示するプロンプトを出力。
- **ワンクリックコピー＆共有**: プロンプトコピー、除外指示（Negative Prompt）コピー、共有URL生成、JSONプリセット保存を完備。

## 📱 スマートフォンでのご利用方法

1. ブラウザ（SafariまたはChrome）で公開URLを開きます。
2. **iPhoneの場合**:
   - 画面下の共有ボタン（四角から矢印のアイコン）をタップ
   - **「ホーム画面に追加」** を選択
3. **Androidの場合**:
   - メニュー（縦の3点リーダー）をタップ
   - **「アプリをインストール」** または **「ホーム画面に追加」** を選択
4. ホーム画面に真空管アンプ調アイコンが追加され、全画面アプリとして快適にお使いいただけます。

## 💻 ローカル環境での起動方法

パソコンのターミナルから直接動かす場合は、以下のスクリプトを利用できます。

```bash
# ローカルWebサーバーを起動（自動でブラウザが開きます）
./run_server.sh

# スマホ接続モード（同一Wi-Fi内のスマホからアクセスできるQRコードを表示）
./run_mobile.sh
```
